Esse repositório contém todos os códigos utilizados (até o momento) no meu Trabalho de Conclusão de Curso, "Previsão da Entalpia de Formação de Materiais Bidimensionais: Uma Análise Comparativa de Algoritmos de Machine Learning".

A pasta base_jung contém os códigos utilizados na etapa de featurização, a conversão das propriedades dos materiais em features composicionais que serão utilizadas para treinamento do modelo.
Os códigos são baseados nos fornecidos pelo autor do artigo "Gradient Boosted and Statistical Feature Selection Pipeline for Materials Property Predictions", Son Gyo Jung.
